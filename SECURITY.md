# Security policy (foundation)

Report suspected vulnerabilities privately to the repository owner, without sharing real driver PII, financial documents or credentials in public issues. The repository has no deployed supported release.

Do not use real Planfix, bank, payment or 1C credentials in issue reproductions. Use synthetic fixtures and describe exact versions, impact, expected vs observed behavior and test steps. No pentesting of third-party customer services without authorization.

See docs/06-governance/SECURITY_AND_APPROVALS.md and RISK_REGISTER.md.
