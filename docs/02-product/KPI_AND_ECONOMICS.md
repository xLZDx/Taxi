# KPI baseline and value-realization methodology

All values are UNKNOWN until measured from actual taxi-fleet sources. No invented ROI or cost savings.

| KPI | Definition | Baseline | Verification |
|---|---|---|---|
| Source coverage | Vehicles with current authoritative revenue source / active vehicles | UNKNOWN | per-day source inventory |
| Reconciliation coverage | Matched receipts / receipts requiring matching | UNKNOWN | evidence-linked reconciliation rows |
| Cash projection error | abs(forecast - settled cash) at selected forecast horizon | UNKNOWN | historical backtesting |
| Investor payout readiness | Liquidity after protected obligations / payout due on 10th | UNKNOWN | bank-cleared + liabilities |
| Driver report lag | Days between period end and confirmed driver reporting | stated 7–14 days, UNVERIFIED | dated report events |
| Overdue cash | Collected vs not-yet-collected amounts past agreed date | UNKNOWN | aging schedule |
| Vehicle availability | Available vehicle-hours / scheduled hours | UNKNOWN | dispatch/repair |
| Repair downtime | From safety hold to approved return | UNKNOWN | service events |
| Administrative workload | Staff minutes per monthly settlement exception | UNKNOWN | time tracking |
| Approval latency | Time from submitted to authorized decision | UNKNOWN | workflow logs |

Value realization = evidenced avoided leakage + recovered time + reduced unproductive vehicle hours - all provider/license/integration costs. Distinguish observed from hypothesized benefit. Baseline 4+ weeks recommended before signed ROI claims; seasons and driver mix matter.
