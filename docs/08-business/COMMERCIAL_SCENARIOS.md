# Pricing and ownership scenarios (not signed)

| Option | Software IP | Payment basis | Comments |
|---|---|---|---|
| Starter subscription | Provider | Fixed monthly | Default pilot; reporting baseline included |
| Per active vehicle | Provider | Verified vehicle-count period | Audit vehicle activity; cap volatility |
| Usage-based | Provider | Metered events/modules | Needs transparent meters and floor/cap |
| Commission | Provider | Defined attributable technology service event | Avoid ambiguous percentage of taxi revenues |
| License | As contract | Grant for duration/site | Maintenance separate |
| Franchise | As contract | License + methodology/support | Later stage; regulatory and brand review |
| Joint product | Negotiated e.g. 50/50 | Product revenue/profit distribution | IP, deadlock and exit clause essential |
| Hybrid | Negotiated | Setup + subscription + optional usage | Predictable base, variable upside |

A UI selector may offer presets but storage retains independent commercial_model, access_tier, contract and effective version. No subscription is a tax deduction technique. All billing is auditable and distinct from the taxi fleet's operating books.
