# Taxi Automation Platform

Technology partner platform for a 500-vehicle taxi fleet, built Planfix-first. The taxi operator retains full operational control. The initial focus is driver settlement reconciliation, forward cash-flow forecasting for investor payouts due on the 10th, fleet workflows, and auditable Business Plans & Real Reporting.

**Status:** discovery and foundation. The code and workflows are an offline scaffold, not an integrated or production-ready deployment. No live taxi, Planfix, banking or 1C credentials are stored here.

**Delivery:** start with a low-cost subscription, while separating commercial models and access entitlements from operational business logic. Alternative partnership, per-vehicle, commission, license, franchise and hybrid structures remain configurable architectural options.

See the foundation branch and its documentation before committing implementation or production integrations.
